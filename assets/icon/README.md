# App icon

The icon is the upstream Litube artwork with only its hue changed from red `#BB202D` to blue `#0A84FF`.
No new artwork was drawn.

| File | Purpose |
|---|---|
| `icon-512.png` | 512 × 512 store/README icon |
| `icon-light.png`, `icon-dark.png` | 640 × 640 previews on white and on the dark app background |
| `icon-192-source.png` | the xxxhdpi launcher PNG the 512 version was scaled from |
| `png/ic_launcher-<density>.png` | the five launcher densities as shipped (48 → 192 px) |
| `ic_launcher-adaptive.xml` | adaptive-icon descriptor (background / foreground / monochrome) |
| `ic_launcher_foreground.xml` | adaptive foreground vector, blue |
| `ic_litube_mark.xml` | the in-app corner mark (top bar / empty state), blue |

The live copies used by the build are in `app/src/main/res/`; these are copies for reuse outside Android.
